Trabajá exclusivamente en la consolidación del **DOCUMENT SYSTEM** común para todo el grupo.

## OBJETIVO

Crear una única definición documental transversal para:

* Charlie
* CORE
* ODDY
* OnDemand by ODDY
* FACILIA by CORE
* COMITA by CORE
* futuras marcas del grupo

**No diseñar documentos nuevos desde cero.**

El objetivo es auditar, recuperar y reorganizar todo lo que ya existe para convertirlo en un **sistema documental único, coherente y reutilizable**.

La regla fundamental es:

> **Un solo formato documental común.**
>
> **La marca cambia el logo y la identidad; el formato permanece.**

* datos de contacto
* web
* email
* teléfono

> Nombre del documento

> Contenido

# 13. VARIABLES DE MARCA

El sistema debe permitir cambiar únicamente las variables de marca:

```text
brand.name
brand.logo
brand.colors
brand.website
brand.contact
brand.legalName
```

El resto del documento debe permanecer dentro del DOCUMENT SYSTEM.

Ejemplo:

**FACILIA by CORE**

y

**COMITA by CORE**

deben utilizar la misma estructura documental.

Sólo cambia su identidad de marca.

---

# 14. VARIABLES DE CONTENIDO

Separar también:

**Formato**

de:

**Contenido**

El sistema debe permitir reutilizar una plantilla para distintos documentos sin modificar el diseño.

Ejemplo:

> `QuoteTemplate`
>
> * datos del cliente
> * productos/servicios
> * precios
> * condiciones
> * marca

No crear una plantilla independiente para cada cotización.

---

# 17. REGLA FUNDAMENTAL

No crear un "estilo FACILIA para presupuestos", un "estilo COMITA para propuestas", etc.

Debe existir:

> **UN DOCUMENT SYSTEM**

y las marcas deben ser variables.

## CRITERIO DE CIERRE

El trabajo está terminado cuando podamos decir:

> **Existe un único sistema documental para todo el grupo.**
>
> Las marcas no crean sus propios formatos de documentos.
>
> Los documentos utilizan una estructura común y cada marca aporta únicamente su identidad.

**Auditar y consolidar primero. No implementar cambios ni modificar código productivo sin autorización posterior.**
