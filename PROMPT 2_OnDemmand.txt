Trabajá exclusivamente sobre la marca **OnDemand** y su relación con **ODDY**.

## Objetivo

Cerrar la definición visual básica de:

> **OnDemand by ODDY**

para uso en:

* Web
* Redes sociales
* Documentos
* Presentaciones
* Material comercial

### Arquitectura aprobada

**ODDY** es la marca logística / operador territorial.

**OnDemand** es la actividad de transporte internacional / freight / forwarding.

Por lo tanto:

> **OnDemand by ODDY**

debe funcionar como una submarca respaldada por ODDY.

## Qué tenés que hacer

### 1. Auditar primero

Buscar todos los assets existentes relacionados con:

* OnDemand
* On Demand
* OnDemand by ODDY
* ODDY + OnDemand

Incluyendo logos, SVG, PNG, código, documentación, propuestas y assets históricos.

**Reutilizar cualquier asset aprobado que exista.**

No inventar una identidad nueva si ya existe una definición válida.

### 2. Logo

Definir el lockup:

> **OnDemand by ODDY**

Debe quedar claramente establecida la relación jerárquica entre OnDemand y ODDY.

Preparar, cuando corresponda:

* logo principal
* versión positiva
* versión negativa
* versión monocromática
* versiones para fondos claros/oscuros
* versión horizontal
* versión compacta, sólo si es necesaria

No alterar el logo oficial de ODDY.

### 3. Colores

Definir la paleta de OnDemand **alineada con ODDY**.

Primero verificar si ODDY ya posee colores aprobados.

Si ODDY tiene paleta formal, OnDemand debe construirse a partir de ella o de una extensión claramente compatible.

Si no existe una paleta formal de ODDY, **no inventarla y presentarla como aprobada**.

Separar claramente:

* colores heredados de ODDY
* colores propios de OnDemand, si realmente fueran necesarios

### 4. FAVICOM / paquete maestro

Preparar todos los archivos necesarios para:

* Web
* LinkedIn
* Instagram
* Facebook
* WhatsApp
* YouTube
* X
* favicon
* perfiles/avatar
* documentos
* presentaciones

Formatos principales:

* SVG
* PNG
* versiones para fondos claros/oscuros
* archivos vectoriales maestros cuando sea posible

### 5. Entregable

Crear una **Brand Definition — OnDemand by ODDY** breve con:

* arquitectura de marca
* logo
* variantes
* colores
* reglas mínimas de uso
* lista de assets

## Restricciones

NO tocar:

* CORE
* Charlie
* FACILIA
* COMITA
* sistema UI general
* sistema documental

No rediseñar ODDY.

No crear un nuevo Design System.

No inventar una paleta sin evidencia.

**Este trabajo es exclusivamente OnDemand + su relación visual con ODDY.**

Al finalizar, informar exactamente qué assets existentes encontraste, cuáles reutilizaste, cuáles generaste y qué decisiones quedaron pendientes.
